# Recorded follow-up protocol

Fixed before generating the confirmatory records on 24 September 2026. This is a prospective computational specification within this revision, not an external preregistration. Historical results informed the question and design. No result-dependent stopping or choice of cells is permitted.

## Embedding geometry

Generate 10,000 independent datasets in five blocks, with 1,000 reference draws per dataset, from the Gaussian fitted to the saved 28 by 119 normalized fibromyalgia embedding. Use the historical five-restart implementation, k=2 through 6 and the same size guard. Compare M and C on paired source datasets and reference streams. Use new root seed 20260924 and experiment address 71. Retain all dataset seeds, normalized-array hashes, observed cluster sizes, p-values, exceedance counts and reference guard outcomes. Count observed guard failures as nonrejections; never omit them. Numerical failures prevent a completed analysis. Report strict p<0.05 rates, Wilson intervals, paired discordance and each block. This checks the implemented historical reference constructions; fixed-k M lacks the search guard, so it is not a pure normalization experiment. It does not certify C as a level-0.05 test.

## Independent cutoff calibration and detection

Use n=28, d=119; two full-rank spectra: a one-spike two-block spectrum (leading eigenvalue 1, residual eigenvalues 0.01) and an exponential spectrum exp(-j/10), j=0,...,118. Neither is tuned to obtain a favorable result. Use fixed nested random projections to q=5 and q=10. Independently generate 1,000 calibration-null and 1,000 evaluation-null datasets per spectrum. Each evaluation-null dataset has paired mixtures along either the leading or the 60th covariance eigenvector at standardized half-separations 2 and 4, using the first 250 evaluation indices per alternative cell. The mixture noise, random rotation and random signs are shared across directions, strengths and projections at each evaluation index. Use the frozen S16 W, D4, K and E implementations, 199 references and E auxiliary size 200. Save projected squared Mahalanobis half-separation and retained axis length for every dataset. The mixture mean difference is twice the stated half-separation.

Estimate an arm-specific lower-tail p-value cutoff from the independent calibration sample to target empirical size 0.05, randomizing at a tied boundary. Use preaddressed uniform variates for evaluation boundary decisions. Report held-out size with Wilson intervals and an explicitly prespecified descriptive tolerance of 0.03 to 0.07: call a cell compatible with this tolerance only if its entire 95% interval lies inside it. With 1,000 null datasets, the approximate 95% half-width at size 0.05 is 0.0135; this supports a two-percentage-point tolerance, not a one-point guarantee. Alternative cells have 250 paired datasets, giving worst-case half-width about 0.062. Report nominal and calibrated detection separately, without assuming held-out sizes are exactly equal.

Use 2,000 two-stage bootstrap resamples of calibration indices and evaluation indices. Recompute the randomized cutoff within each resample. Preserve pairing across arms and alternatives. Report percentile intervals for calibrated detection rates and pairwise differences, alongside conditional Wilson intervals. These are Monte Carlo uncertainty estimates under the specified simulation laws, not guarantees for other spectra or clinical data. Report all pairwise comparisons descriptively; do not select a winning method using unadjusted significance tests. Numerical failures prevent final summaries. Use root seed 20260924 and distinct experiment address 72. An execution pilot uses a separate root and is excluded from inference.

## Scope

These additions repair record retention and broaden the statistical comparisons. They cannot recover missing raw images or checkpoints, establish clinical subtypes, guarantee editorial novelty, or supply author declarations. The applications remain illustrative downstream analyses. No clinical retraining is represented as completed.
