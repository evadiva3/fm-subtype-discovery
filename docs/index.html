Significance Without Structure

Null misspecification and non-reproducible subtypes in small-sample self-supervised neuroimaging

Eva Bangsil, Nikhil Joshi

We clustered fibromyalgia patients' brain-connectivity embeddings, got four clean subtypes at p = 0.024, and then could not reproduce them. The problem was not the clustering. It was the significance test. The permutation null had two independent errors in it, and either one alone was enough to manufacture a discovery.

This page runs that null in your browser, on the actual 28 × 119 embedding matrix from the paper. Nothing here is precomputed. The k-means, the silhouette and the null draws are all computed as you watch. Turn the two corrections on and off and the same data stops being significant.

What you just did

A permutation null is only valid if every draw goes through the same procedure that produced the observed number. Ours failed that twice.

Geometry. The observed embeddings are L2-normalized onto the unit sphere before clustering. The null draws were sampled in ambient space and never projected, so they carry radial spread the real data cannot have. That makes them harder to cluster, which pushes null silhouettes down, which pushes p down.

Selection. The reported silhouette is a maximum over k ∈ {2…6}, picked after seeing the data, but each null draw was scored at one fixed k. The null never got the same search the observed statistic did. Given it, 33.8% of null draws maximize at k = 2 and only 25.3% at the k = 4 we picked.

Neither error is exotic, and both are easy to write by accident. Measured against 1,000 structureless datasets, the misspecified construction rejects 20.5% of the time against a nominal 5%. Corrected, it rejects 0.4% of the time. Across 1,000 paired comparisons the misspecified test produced 201 rejections the corrected test did not, and none the other way.

Why this exists

This started as a fibromyalgia subtyping project. The subtypes did not survive retraining on byte-identical inputs, and chasing that turned it into a methods paper. The reproducibility checks never invoke a null at all, and they were right the whole time while the significance test was not. Across two disorders and 40 end-to-end runs, nothing reaches nominal significance once the null is built correctly.

Method note. Draws come from a Gaussian fitted to the normalized embedding. The covariance is Σ = AᵀA with A the centered matrix over √(n−1), so a draw is just μ + zA for z ~ N(0, I₂₈). No eigendecomposition, which is why this runs in a browser at all. k-means uses the same 20 restarts as the paper, so the only difference from the published values is Monte-Carlo noise from the draw count. The Python and JavaScript silhouettes agree to seven decimals on the observed partition (0.2433061).
